Proyek: Petualangan Sahabat Nusantara (PWA Web Game)
Panduan praktis, komprehensif, dan langsung pada intinya mengenai seluruh perangkat lunak (tools), teknologi frontend, audio synthesizer prosedural, Progressive Web App (PWA), serta pengujian otomatis yang digunakan untuk merekayasa game dari nol hingga tahap rilis.

  • Frontend: HTML5 Semantic + CSS3 Modular (Dynamic Viewport 100dvh)
  • Logic & State: Vanilla JavaScript ES6+ (Router Layar Asli)
  • Audio Engine: Web Audio API (Sintesis Suara Tanpa File MP3)
  • PWA & Offline: Service Worker v2 (Network-First Cache) + Web Manifest
  • QA Testing: Microsoft Edge Chromium Headless + Chrome DevTools Protocol
  • Hosting & CI/CD: GitHub Pages & Git Version Control

1. ARSITEKTUR & PENDEKATAN "VANILLA STACK"

Game Petualangan Sahabat Nusantara dirancang dengan prinsip Vanilla Web Stack Modern, yaitu membangun aplikasi web interaktif tanpa bergantung pada framework berat pihak ketiga (seperti React, Angular, Vue, atau engine game WebGL seperti Unity/Phaser yang menghasilkan bundle 20MB - 50MB).

Kriteria Performa Engine Konvensional (Unity / Heavy Framework) Pendekatan Sahabat Nusantara (Vanilla PWA)
Ukuran Total Bundle 25 MB – 60 MB (berat untuk kuota seluler) < 6 MB (termasuk seluruh aset gambar resolusi tinggi)
Kecepatan Muat (LCP) 5 – 15 detik (perlu splash screen lama) < 0.8 detik (instan dibuka di smartphone)
Kebutuhan RAM Perangkat > 2 GB RAM (sering lag di HP entry-level) < 150 MB RAM (berjalan mulus di ponsel murah sekalipun)
Aksesibilitas Offline Memerlukan konfigurasi kompleks IndexedDB 100% Offline Otomatis via Service Worker v2
2. DAFTAR PERANGKAT LUNAK & LINGKUNGAN PENGEMBANGAN
1. Visual Studio Code & Antigravity Studio Code Editor / IDE
Editor kode utama untuk menyunting HTML, CSS, JavaScript, dan Markdown secara terstruktur. Dilengkapi ekstensi Live Server untuk live preview dan GitLens untuk pelacakan versi baris demi baris.
2. Node.js (LTS v20+ / v24.x) & Native HTTP Server Local Runtime & Server
Menjalankan server web pengujian lokal menggunakan file server.js yang dibuat murni dengan modul bawaan Node.js (http, fs, path) tanpa perlu menginstal dependensi npm pihak ketiga. 
// Perintah menjalankan server lokal:
node server.js
// Berjalan di port: http://localhost:3000
3. Git CLI & GitHub Pages Version Control & Cloud Hosting
Git digunakan untuk versioning kode terdistribusi. GitHub Pages bertindak sebagai CDN hosting statis global gratis dengan sertifikat keamanan SSL/HTTPS otomatis (wajib untuk Service Worker PWA).
3. TEKNOLOGI INTI FRONTEND & FILE STRUKTUR
HTML5 Semantic & State Router Layar Frontend Markup
File index.html menyusun game ke dalam 6 layar modular (Title Screen, Map Screen, Island Hub Dialog, Quiz Screen, Jukebox Modal, Profile Modal). Setiap layar diaktifkan atau dinonaktifkan secara instan oleh state router di js/app.js melalui manipulasi class .active.
CSS3 Modular & Dynamic Viewport (100dvh) Styling & Responsiveness
Terbagi atas css/main.css, css/components.css, dan css/animations.css. Menggunakan unit 100dvh (Dynamic Viewport Height) untuk mengatasi bilah address bar browser ponsel yang sering memotong layar. Dilengkapi media query ketat untuk mode Mobile Landscape (tinggi layar 300px - 320px).
Basis Data Budaya Terstruktur (JSON) Database
File js/game-data.js memuat 402 butir data budaya terstruktur (300 soal pilihan ganda, 30 soal tebak gambar, dan 18 level tap-matching) yang mencakup 6 zona budaya di seluruh 38 provinsi Indonesia.
4. AUDIO ENGINE: SINTESIS SUARA PROSEDURAL (WEB AUDIO API)

Salah satu inovasi paling menonjol pada game ini adalah ketiadaan file MP3 eksternal. Semua audio (efek tombol, suara benar/salah, hingga 6 instrumen musik daerah) disintesis secara dinamis via kode matematika gelombang menggunakan Web Audio API di file js/audio-synth.js.

Nama Instrumen Musik Nusantara Prinsip Sintesis Web Audio API Ciri Khas Akustik Budaya
Gamelan Degung Jawa Oscillator sine + triangle dengan decay cepat & detune logam Dentang bilah perunggu gamelan khas keraton Jawa & Sunda
Angklung Bambu Sunda Tremolo cepat (12Hz) memodulasi gain gelombang triangle Suara getaran tabung bambu yang digoyangkan serentak
Sasando Petik Rote (NTT) Arpeggio nada tinggi frekuensi 520Hz – 1040Hz jernih Dentingan senar dawai petik khas Pulau Rote
Kolintang Minahasa (Sulawesi) Gelombang sine rendah dengan resonansi kayu hangat Pukulan bilah kayu melodi khas tanah Minahasa
Rampak Tari Saman (Aceh) Ketukan ritmis akseleratif dengan filter frekuensi dinamis Tepukan dada dan paha berenergi tinggi khas Gayo
Poco-Poco Maluku Square bassline berulang dengan irama dansa riang Musik dansa tradisional Maluku yang membangkitkan semangat
5. PROGRESSIVE WEB APP (PWA) & SERVICE WORKER V2
Web App Manifest (manifest.json) PWA Configuration
Mengatur game agar dapat diinstal ke layar beranda smartphone (*Add to Home Screen*), mengunci orientasi ke landscape ("orientation": "landscape"), menjalankan mode fullscreen tanpa bilah browser ("display": "fullscreen"), dan menetapkan warna tema emas Nusantara ("theme_color": "#b45309").
Service Worker v2 (sw.js) Offline & Caching
Menerapkan strategi Network-First: selalu mengambil file terbaru saat terhubung ke internet, lalu menyimpannya ke cache sahabat-nusantara-v2. Jika koneksi terputus, game langsung disajikan dari cache lokal sehingga dapat dimainkan 100% tanpa internet.
6. TOOLS PENGUJIAN OTOMATIS (QA & CROSS-DEVICE TESTING)
Microsoft Edge Headless via Chrome DevTools Protocol (CDP) Automated Testing
Skrip scratch/verify_all_mobile_and_desktop.js menjalankan browser Edge dalam mode headless tanpa GUI untuk menguji:
  • Layar Desktop (1280x720): Memverifikasi tampilan tombol karakter pil lebar tetap aktif dan overlay putar layar tersembunyi total.
  • Layar Mobile Landscape (800x320): Menguji fungsi tombol panah karakter [ ◀ ] dan [ ▶ ], memastikan seluruh 4 tombol menu kanan terlihat (tidak terpotong), serta mengecek ketiga kartu misi di Jawa Hub tampil utuh.
  • Layar Kuis & Tebak Gambar: Memverifikasi foto candi terskala proporsional (≤ 65px) dan 4 opsi jawaban terlihat lengkap.
